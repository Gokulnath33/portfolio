The root `index.html` bootstraps the React SPA built by `vite.config.js`, which registers the React plugin and excludes large static assets (PDFs, ZIPs) from dev watch to keep HMR fast. The `portfolio_app` child provides all React components and page logic under `src/`, while the `certificates_assets` child supplies PDFs and branding images referenced at runtime; both are consumed by the same React codebase. Shared cross-cutting concerns live at the root — Tailwind theme extensions (brand palette, fonts, dark-mode via `[data-theme="dark"]`) in `tailwind.config.js`, PostCSS/Autoprefixer pipeline in `postcss.config.js`, and Oxlint rules in `.oxlintrc.json` — so every component across children renders with consistent styling, theming, and linting.
