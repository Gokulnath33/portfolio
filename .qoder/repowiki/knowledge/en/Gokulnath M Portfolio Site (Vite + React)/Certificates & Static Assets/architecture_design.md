Pure static asset store with no source code or build logic. Two parallel directory trees mirror each other: `CERT/` holds the canonical copies of all certificates grouped by issuer (AICTE PARAKH, GOOGLE CERT, HACKERRANK CERT, HCL GUVI, IEEE CERT... & AI BADGE, INFOSYS CERT, LINKEDIN CERT, MATHS RAMANUJA CERT, NPTEL RESULT, SIMPLY LEARN CERT, TCS ION CERT), while `public/certificates/` is a flattened copy intended for web serving alongside `public/favicon.svg`, `public/icons.svg`, `public/logo.png`, and `public/certificates.zip`. There are no scripts, manifests, or configuration files — assets are consumed directly by the hosting site via relative paths.
