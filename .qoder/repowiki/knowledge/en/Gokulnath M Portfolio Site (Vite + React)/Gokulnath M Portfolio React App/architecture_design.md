Entry point `src/main.jsx` mounts `<App />` into the DOM via ReactDOM. `App.jsx` is the root layout component that owns global theme state (`dark`/`light`) persisted in `localStorage` under `gokulnath_portfolio_theme` and applies it by setting `data-theme` on `document.documentElement`; it also manages a one-time welcome splash via `sessionStorage`. It composes the page as a vertical stack of section components (`Hero`, `About`, `Skills`, `Projects`, `Experience`, `Certificates`, `Resume`, `Contact`) plus shared chrome (`Navbar`, `Footer`) and ambient layers (`DynamicBackground`, `BackgroundMusic`, `CursorFireTrail`). All site content — personal info, education, skills categories, projects, experience, and ~60+ certifications — is centralized as plain exported JS objects/arrays in `src/data/portfolioData.js`, keeping components purely presentational. External integrations are isolated: email delivery lives in `src/config/emailjs.js`, which exports an `EMAILJS_CONFIG` object and a `sendContactEmail` helper that conditionally uses `@emailjs/browser` when real keys are configured or falls back to a simulated send when placeholder values are detected. Assets live under `src/assets/`. Styling is applied via Tailwind CSS utility classes throughout JSX with global rules in `index.css` and `App.css`.
