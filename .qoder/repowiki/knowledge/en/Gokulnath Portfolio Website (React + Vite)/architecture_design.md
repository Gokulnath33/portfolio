The root acts as the Vite project entry point: `index.html` bootstraps the React app built by `vite.config.js`, which registers the React plugin and excludes large static assets (PDFs, ZIPs, certificates) from dev watch to keep HMR fast. The `portfolio_app` child provides all React components and page logic, while `certificates_assets` supplies PDFs and branding images referenced at runtime; both are consumed by the same React codebase under `src/`. Shared cross-cutting concerns live at the root — Tailwind theme extensions (brand palette, fonts, dark-mode via `[data-theme="dark"]`) in `tailwind.config.js` plus PostCSS/Autoprefixer pipeline in `postcss.config.js` — so every component across children renders with consistent styling and theming. Linting is unified via `oxlint` configured in `.oxlintrc.json`.
