The app is a standard React + Vite SPA rooted at `src/main.jsx`, which mounts `<App />` into the DOM. `App.jsx` is the top-level layout component that owns global theme state (`dark`/`light`) persisted in `localStorage` under `gokulnath_portfolio_theme` and applies it via a `data-theme` attribute on `document.documentElement`. It composes a vertical page of section components — `Hero`, `About`, `Skills`, `Projects`, `Experience`, `Certificates`, `Contact`, plus shared chrome `Navbar`, `Footer`, and ambient layers `DynamicBackground` and `BackgroundMusic`. All static content (personal info, education, skills categories, projects, experience, and ~60+ certifications) is centralized in `src/data/portfolioData.js` as plain exported JS objects/arrays, keeping components purely presentational. External integrations are isolated: email sending lives in `src/config/emailjs.js` using `@emailjs/browser` with a configurable `EMAILJS_CONFIG` object that falls back to a simulated send when placeholder keys are detected. Assets (images, logo, SVGs) sit under `src/assets/`. Styling uses Tailwind CSS utility classes throughout JSX plus global rules in `index.css` and `App.css`.
